    About

    How a simple project became a vision for smarter theater systems

    "What started as a school project became a vision."

    Marquee Cinemas began as a simple POS simulation for academic requirements — but it quickly evolved into something more. We saw not just a grade, but a gap: the need for a minimal, intuitive, and well-structured theater management system that prioritizes usability without unnecessary complexity.

    Today, Marquee Cinemas isn't just a showcase of code — it's a statement of what's possible when curiosity meets clarity. Designed with both functionality and experience in mind, it brings together seamless ticketing, movie browsing, and concession handling in one streamlined platform.

    Built by a student, inspired by real-world systems, and driven by a passion for clean interfaces, Marquee Cinemas stands as a testament to how small ideas can lead to big innovations.

    FAQs

    Answers to common questions about our app and how it works.

    What is Marquee Cinemas?

    Marquee Cinemas is a theater POS simulation for managing tickets, movies, and concessions. Built using Java (Swing & AWT) with NetBeans' drag-and-drop tools, it began as a student project and grew into a polished example of functional UI design.

    Can I use Marquee Cinemas in a real theater?

    While originally built as a simulation, Marquee Cinemas was developed with real-world functionality in mind. It has the potential to be adapted for actual theater use by anyone interested in taking over or building on the system.

    What features does Marquee Cinemas offer?

    Marquee Cinemas includes Ticket Management, Movie Selection, Snacks & Beverages handling, multiple modes of payment, integrated account registration, and viewable lists of both admins and employees — all wrapped in a clean and minimal interface.

    Is Marquee Cinemas available on mobile or web?

    No. Marquee Cinemas is a desktop application built with Java Swing and AWT. It does not have a mobile or web version.

    How do I run Marquee Cinemas on my computer?

    You’ll need to have Java installed. Download the project from GitHub and open it in NetBeans. From there, you can build and run the app through the IDE.

    Is the source code open for modification?

    Yes. The full source code is available on GitHub: https://github.com/theojohnsosa/marquee-cinemas. You’re free to explore, modify, or expand it as you see fit.
